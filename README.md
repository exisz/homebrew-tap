# Homebrew Tap — exisz

Homebrew formulae for [exisz](https://github.com/exisz) open source tools.

## Install

```bash
brew tap exisz/tap
brew install bitgit
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [agent-git](https://github.com/exisz/agent-git) | A git wrapper that tracks cloned repos and prevents duplicate clones |
| [bitgit](https://github.com/exisz/bitgit) | Git + Bitbucket DC CLI with a hook-based plugin system |
| [lazyjira](https://github.com/gotexis/lazyjira) | Zero-dependency CLI for Jira Cloud |
